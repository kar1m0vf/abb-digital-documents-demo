# Данные для проверки проекта

Этот файл предназначен для разработчика и ведущего показа. Тестовые значения и подсказки не отображаются в интерфейсе. Внизу страниц есть компактная подпись о том, что это презентационный прототип, а не официальный сайт ABB.

## Вход и оплата

| Поле | Значение |
| --- | --- |
| FİN | `ABC1234` |
| OTP | `123456` |
| Карта: успешная оплата | `4242 4242 4242 4242` |
| Карта: отклонённая оплата | `4000 0000 0000 0002` |
| Срок действия | `12/30` |
| CVV / CVC | `123` |

Вводите значения вручную. FİN и OTP можно вставлять целиком в первое поле. Кнопок заполнения тестовой карты на сайте нет. После отказа замените номер карты на успешный и снова введите CVV: при отправке платежа это поле очищается.

Другие FİN и номера карт не принимаются. Для проверки ошибочного OTP подойдёт `000000`. Лимит — 5 попыток; код действует 5 минут, повторный запрос доступен через 60 секунд. Успешно применённый OTP нельзя использовать повторно. Срок карты должен быть действующим: после 2030 года используйте будущую дату в формате `MM/YY`. Валидируется трёхзначный CVV.

## Документы и расчёты

- Выписка (`statement`): **5 AZN**. Справка (`reference`): **10 AZN**.
- Комиссия: **0 AZN**; одна объединённая копия независимо от числа счетов.
- Фиксированные курсы: 1 USD = **1.7 AZN**, 1 EUR = **1.9 AZN**.
- Посольства: Италия, Германия, Франция, Испания, Великобритания.
- По умолчанию: выписка, Италия, английский язык, без выбранных продуктов.
- Периоды выписки: 1, 3, 6, 12 месяцев или собственные даты. Операции: все, входящие, исходящие.
- Новый номер заказа: `AR-ГОД-XXXXXXXX`. Старые номера `DEMO-ГОД-XXXXXXXX` отображаются с префиксом `AR`, сохранённые статусы сохраняются.
- Статусы: `pending`, `completed`, `rejected`.

## Технические границы

Сайт остаётся локальным прототипом: SMS, банковские запросы, реальное списание, электронная подпись и доставка в посольство не подключены. Удаление пояснений из интерфейса этого не меняет. Используйте только данные из этого файла; созданные PDF не являются официальными банковскими документами.

Рабочие константы остаются в JavaScript, чтобы сценарий продолжал выполняться; этот Markdown не загружается интерфейсом. Заказы и статусы сохраняются в localStorage (`abb-bda-demo-orders-v1`, `abb-bda-demo-statuses-v1`), до 100 заказов. FİN, OTP и данные оплаты не сохраняются. Незавершённый заказ и авторизация сбрасываются при перезагрузке страницы. Полного разграничения доступа к кабинетам нет.

## Публикация

В HTML добавлен robots meta-тег noindex, nofollow; встроенный Node-сервер также возвращает X-Robots-Tag. При статическом хостинге meta-тег сохраняется, серверный заголовок зависит от хостинга. Не блокируйте весь сайт через robots.txt: поисковому роботу нужно прочитать noindex.

Запрет индексации исключает страницы из поиска после обработки роботом, но не гарантирует отсутствие предупреждения Google Safe Browsing. Для закрытой презентации можно дополнительно использовать защиту паролем на хостинге. Адрес публикации не должен выдавать себя за официальный домен банка.
